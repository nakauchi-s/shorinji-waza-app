# 少林寺拳法 技抽出アプリ

## 概要
少林寺拳法の技を、指定した条件からランダムに抽出するWebアプリです。
スマートフォン・PCのブラウザで利用できます。
技データはExcelで管理し、ExcelからJSONファイルへ変換することで、プログラムを変更せずにデータ更新が可能です。

## 主な機能
### 技抽出
* 条件指定による技の抽出
* ランダム出題
* 一度抽出した技は再抽出されない（リセットまで）
* 「次の技」で次の問題へ移動

### 抽出条件
* 拳系（複数選択）
* 階級範囲
* 分類（剛法・柔法など）

### 技情報表示
表示項目：
* 技名
* 読み
* 拳系
* 階級
* 分類
* 構え
* 攻者構え
* 攻撃方法
* 守者構え
* 守法
* 教範頁

### 音声機能
* 技名の読み上げ機能
* ON/OFF切替可能

### 参考資料表示
技ごとに参考資料を表示できます。
対応資料：
* PDF
* 動画
参考資料が登録されていない技は、資料ボタンを表示しません。

# 利用方法
## Webサーバーへ配置
本アプリはHTML＋JavaScriptで作成されています。
Webサーバーの公開フォルダへ、以下のファイル一式を配置してください。

index.html
app.js
style.css
dataフォルダ
pdfフォルダ

配置後、ブラウザから `index.html` にアクセスしてください。

# データ更新方法
## 1. Excelを編集
`excel` フォルダ内のExcelファイルを更新します。
管理データ：

### 技リスト
技情報を管理します。
主な項目：
* ID
* 拳系CD
* 技名
* 読み
* 階級CD
* 分類CD
* 構え
* 攻撃方法
* 守法
* 教範頁

### 参考資料マスタ
技ごとの資料を管理します。
主な項目：
* 資料ID
* 技ID
* 種類（PDF／動画）
* 表示順
* タイトル
* 参照先
* 備考

技IDをキーとして、技リストと紐付けます。

## 2. JSON変換
Node.jsを利用して変換します。
プロジェクトフォルダで以下を実行します。
```
node tools/excelToJson.js
```
成功すると以下のJSONファイルが更新されます。

data
├─ waza.json
├─ punch.json
├─ rank.json
├─ category.json
└─ reference.json

## 3. サーバーへ反映
更新された `data` フォルダをWebサーバーへ配置してください。

# PDFファイルについて
PDF資料は `pdf` フォルダへ配置してください。
参考資料マスタの「参照先」には、配置したファイル名を設定します。
例：
```
pdf/
 └ 少林寺拳法教範(下巻抜粋)_200-201.pdf
```

参考資料マスタ：
```
参照先：
少林寺拳法教範(下巻抜粋)_200-201.pdf
```

# 動画について
動画は以下に対応しています。
* Web上の動画URL
* MP4ファイル

例：
```
https://example.com/movie.mp4
```
または
```
movie.mp4
```

# 注意事項
* JSONファイルを直接編集する必要はありません。
* データ更新はExcelを修正してください。
* Excel更新後は必ずJSON変換を実行してください。
* PDFファイル名を変更した場合は、参考資料マスタの参照先も変更してください。
